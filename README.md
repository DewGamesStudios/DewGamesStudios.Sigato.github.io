# Sigato - Live Production Server & Game Meta Hub

Welcome to the centralized live backend and resource configurations repository for **Sigato**, a multiplayer 2D digital board game active on the Google Play Store. This repository serves as a lightweight remote-configuration server handles asset fetching and system update metadata.

---

## 📱 About Sigato
Sigato is a competitive multiplayer 2D board game showcasing real-time client-server communication pipelines. 
* **Core Architecture:** Built utilizing Unity, Photon (PUN) real-time matching nodes, and decoupled state management.
* **Live Status:** Production-ready and distributed across global Android deployment networks.
