# Sigato - Live Production Server & Game Meta Hub

Welcome to the centralized live backend and resource configurations repository for **Sigato**, a cross-platform multiplayer 2D digital board game. This repository serves as a lightweight remote-configuration server handling live asset fetching and system update metadata.

---

## 📱 About Sigato
Sigato is a competitive, multi-platform multiplayer board game showcasing real-time client-server communication pipelines. 
* **Universal Responsive UI:** Architected with a dynamic layout system that automatically scales and shifts layouts fluidly across PC, Windows Desktop, and Android/iOS Mobile viewports.
* **Core Architecture:** Built utilizing Unity, Photon (PUN) real-time matching nodes, and fully decoupled UI state management.
* **Live Status:** Production-ready, stable, and distributed across global Android deployment networks.
